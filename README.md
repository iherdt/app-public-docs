# app-public-docs

Public, app-facing documentation for App Store submissions.

## Paths

- `focusrep/` – FocusRep links (privacy policy, terms)
- `calrun/` – CalRun links (privacy policy, terms)

## GitHub Pages

Enable GitHub Pages for this repository (Settings → Pages) and serve from the `main` branch root.

Then use URLs like:

- `https://<username>.github.io/<repo>/focusrep/privacy`
- `https://<username>.github.io/<repo>/focusrep/terms`
